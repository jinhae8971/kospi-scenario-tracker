# 코스피 2026 급락장 시나리오 트래커

2026년 6월 고점(9,385.59) 이후 진행 중인 코스피 조정을, **역사적 유사사례에서 도출한 3개 시나리오 경로**와 매 영업일 종가로 대조하여 "지금 시장이 어느 시나리오를 따라가고 있는가"를 확률로 갱신하는 대시보드입니다.

**대시보드:** https://jinhae8971.github.io/kospi-scenario-tracker/

> 본 저장소는 개인 리서치 기록용입니다. 투자 자문이 아니며, 시나리오 경로는 과거 사례를 현재 지수에 오버레이한 추정치입니다.

| **A** | V자 정상화 | 25% | 코스피 2020 / 2024.8 엔캐리 청산 | 메모리 계약가·하이퍼스케일러 capex 유지, 신용융자 8월 중 소화 |

기준일(base_date)은 **2026-07-31**, 기준값 6,595.45. 이 날짜 이전 관측치는 확률 평가에서 제외됩니다.

## 2. 확률 갱신 방식

각 시나리오는 월별 앵커 포인트로 정의된 경로를 가지며, 임의 일자의 기대값은 **일자 기준 선형보간**으로 계산합니다.

```
오차_t   = (실제종가_t − 기대값_t) / 기대값_t
RMSE_i   = sqrt( mean( 오차_t² ) )            # 기준일 이후 전 관측치
사후확률_i ∝ 사전확률_i × exp( −RMSE_i / τ )   # τ = 0.055
```

τ가 작을수록 최근 이탈에 민감하게 반응합니다. 관측이 누적될수록 사전확률의 영향은 자연히 희석됩니다.

## 4. 수집 지표

- 코스피 종가 (KRX 지수코드 1001)
- 삼성전자(005930) / SK하이닉스(000660) 종가 — 지수 왜곡 여부 판별용
- 외국인 순매수 누적 (KOSPI 전체)
- 고점 대비 낙폭

### 데이터 소스

| 순위 | 소스 | 엔드포인트 | 비고 |
|------|------|-----------|------|
| 1 | 네이버 금융 | `api.finance.naver.com/siseJson.naver` | 지수·개별종목 OHLCV, 인증 불필요 |
| 1 | 네이버 모바일 | `m.stock.naver.com/api/index/KOSPI/trend` | 외국인/기관/개인 순매수 (당일 기준) |
| 2 | yfinance | `^KS11`, `005930.KS`, `000660.KS` | 네이버 장애 시 폴백 (수급 데이터 없음) |

> **pykrx는 사용하지 않습니다.** 1.2.x 부터 `KRX_ID`/`KRX_PW` 환경변수 로그인이 필수가 되어 무인 실행이 불가능하고, `data.krx.co.kr` 직접 호출도 세션 없이는 `LOGOUT`을 반환합니다.
>
> 외국인 순매수는 당일 기준 조회만 가능하므로, `workflow_dispatch`로 과거 일자를 백필하면 지수·종목 종가는 채워지지만 수급은 `null`로 남습니다.

## 5. 자동화

`.github/workflows/kospi-tracker.yml`

- **스케줄:** 평일 KST 17:00 (UTC 08:00, `cron: 0 8 * * 1-5`) — 장 마감 15:30 + KRX 정산 버퍼
- **수동 실행:** `workflow_dispatch`, `date` 입력(YYYY-MM-DD)으로 특정 일자 백필 가능
- 종가 수집 → 시나리오 평가 → `docs/data/history.json` 커밋 → 텔레그램 요약 발송
- 휴장일은 변경 없음으로 감지되어 커밋을 건너뜁니다
- 실패 시 텔레그램 알림

### 필요한 Secrets

| 이름 | 용도 |
|------|------|
| `TELEGRAM_TOKEN` | 봇 토큰 |
| `TELEGRAM_CHAT_ID` | 수신 채팅 ID |

## 6. 구조

```
├── tracker.py                    # 수집 + 시나리오 평가 + 알림
├── scenarios.json                # 시나리오 경로·사전확률·트리거 (단일 진실 원천)
├── requirements.txt
├── .github/workflows/
│   └── kospi-tracker.yml
└── docs/                         # GitHub Pages 루트
    ├── index.html                # 대시보드
    ├── scenarios.json            # 워크플로우가 루트에서 자동 동기화
    └── data/history.json         # 누적 시계열 + 평가 결과 + 이벤트
```

## 7. 로컬 실행

```bash
pip install -r requirements.txt
python tracker.py                 # 오늘 종가
python tracker.py 2026-08-14      # 특정 일자
```

텔레그램 자격증명은 환경변수 우선, 없으면 `config.json`(gitignore됨)에서 읽습니다.

```json
{ "TELEGRAM_TOKEN": "...", "TELEGRAM_CHAT_ID": "..." }
```

## 8. 시나리오 수정

`scenarios.json`의 `path` 배열만 고치면 됩니다. 대시보드와 트래커가 동일 파일을 읽으므로 별도 코드 수정이 필요 없습니다. 수정 후 push하면 다음 실행부터 새 경로로 사후확률이 재계산됩니다.
